# 影印紙用印量統計

讀取影印機匯出的「N月印量.xlsx」與帳號列表 .csv,統計各班、各使用者的用印量與費用。
**所有計算都在瀏覽器內完成,資料不會上傳到任何伺服器**(本 repo 也不包含任何印量資料)。

## 使用
- 線上版:開啟本 repo 的 GitHub Pages 網址。
- 離線版:下載整個資料夾,雙擊 `index.html`(建議 Chrome / Edge)。

第一次按「連結『資料』資料夾」選放印量檔的資料夾;之後新檔案放進去,按「↻ 重新讀取」即可。
詳細說明見 [使用說明.txt](使用說明.txt)。

## 檔案
| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面骨架 |
| `style.css` | 樣式(含深色模式、列印樣式) |
| `app.js` | 全部邏輯:讀檔 → 整理 → 計費 → 畫面 |
| `vendor/xlsx.full.min.js` | SheetJS 0.18.5(Apache-2.0),讀 Excel 用 |

## 計費(沿用 Excel「工作表2」N:Q 欄公式)
單價:A4 0.25、B4 0.3、其他 0.4 元/面
- 列印費 = 單價 × 列印面數
- 裝訂費 = (1 針 0.25、2 針 0.5)× 份數
- 紙張費 = 單價 × (列印面數 + 補計 × 係數);雙面且頁數為奇數時補計 = 份數,係數:頁數 1 或單面為 1,其餘 0.5

## 調整設定
`app.js` 開頭的 `CONFIG`:班級、科目中文名稱、各班人數、預收金額、老師額度、預設起算日。
